# 1D Reservoir Geomechanics Simulator

## Objective
A Python-based engineering tool designed to compute in-situ effective stresses, resolve normal and shear stresses on inclined fault planes, and evaluate rock stability using the Mohr-Coulomb failure criterion.

## Tech Stack
* **Python:** Core logic
* **Pandas:** Field data processing
* **NumPy:** Trigonometric arrays for stress resolution
* **Matplotlib:** Mohr's circle visualization

## How to Run
Run `visualizer.py` to process the well data and generate the Mohr's Circle stress analysis.
